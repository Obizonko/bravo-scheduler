# Bravo Dashboard

Веб-інтерфейс для керування розкладом та змінами Браво.

## 📌 Опис

Bravo Dashboard — це система для зручного перегляду змін, контролю навантаження та взаємодії.

Основна мета — спростити організацію чергувань і зробити інформацію про поточні та майбутні зміни доступною в одному місці.

## 🚀 Функціонал

- Перегляд особистого розкладу
- Перегляд усіх змін протягом дня
- Відображення поточних та наступних чергувань
- Можливість повідомити про необхідність заміни
- Моніторинг активних змін

## 🛠 Технології

- HTML
- CSS
- JavaScript
- Tailwind CSS

## 📱 Інтерфейс

Проєкт адаптований під мобільні пристрої та створений з урахуванням зручності використання під час роботи на локації.


або використати локальний сервер у VS Code (Live Server).
