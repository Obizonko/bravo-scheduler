# Bravo Dashboard

Веб-інтерфейс для сторінки «Люди» (загальний огляд, без входу), тижневих календарів служб
«Склад»/«ТЕЦ»/«Водії», загального «Майстер-плану» та особистого календаря кожної людини.
Статичні HTML/CSS/JS, без білд-кроку - backend (`../backend`) сервить цю папку напряму (`GET /`).

## Функціонал

- **Люди** (`index.html`) - загальна сторінка (не персоналізована): список людей, хто зараз
  де чергує + керування ростером (додати/видалити людину, для адмінів). Клік на людину -
  модалка з календарем: вкладка «Чергування» (тижневий календар годин×днів, лише перегляд,
  той самий формат, що й Склад/ТЕЦ/Майстер-план, `GET /people/:id/calendar`) і вкладка
  «Активності» (агенда Master Plan за місяць з перемикачем участі,
  `GET/POST/DELETE /activity-assignments`).
- **Склад / ТЕЦ** (`sklad.html` / `tec.html`) - справжній тижневий календар (як Google
  Calendar week view): вертикальна шкала годин, 7 днів по горизонталі, у кожному дні - до
  3 (Склад) / 2 (ТЕЦ) паралельних слот-колонок, підписаних за черговістю (1/2/3). Клік у
  слоті створює зміну дефолтної тривалості, перетягування - довільної; ручка знизу розтягує
  наявну; порожній слот показує `<select>` для вибору людини (`GET /shifts/week-board`,
  `POST /schedule/check`, `POST /schedule`, `PUT /shifts/:id`, `DELETE /schedule/:id`,
  `DELETE /shifts/:id`). Лише на Складі колонки 2/3 підсвічуються сірим у проміжки, де за
  рівнем навантаження з майстер-плану відповідна людина не потрібна (візуальна підказка,
  призначити туди все одно можна).
- **Водії** (`vodii.html`) - тижневий грід навпаки: рядок на людину (водії - першими),
  колонка на день; у кожній клітинці - інтервали зайнятості (виїзди), що додаються прямо
  в клітинці цієї людини й дня.
- **Майстер-план** (`masterplan.html`) - загальна програма табору, той самий тижневий
  календар (години×дні), але кількість паралельних доріжок НЕ фіксована - активності
  авто-пакуються без обмеження (скільки завгодно подій одночасно). Клік/драг створює
  активність (дефолтна назва - клікніть по бару відредагувати назву/рівень
  навантаження/«щодня» в модалці). Рівень навантаження (низьке=1 людина, середнє=2,
  високе=3) саме звідси підсвічує колонки на Складі. Модалка редагування активності має
  другу вкладку «Люди» - простий перелік усіх людей з перемикачем участі в цій конкретній
  активності, без потреби заходити в кожну людину окремо (`GET /users`,
  `GET/POST/DELETE /activity-assignments?master_plan_id=`).
- **Моніторинг** (`monitoring.html`) - зведений стан усіх служб (`GET /api/v1/status`).
- **Вхід** (`login.html`) - PIN голови команди або супер-адміна (`POST /api/v1/auth/pin`),
  сесія - у `sessionStorage` вкладки (не зберігається довше).
- **Адміни** (`admins.html`) - призначення/зняття ролі `lead`, лише для супер-адміна
  (`PUT /api/v1/users/:id`).

## Технології

Ванільні HTML/CSS/JS, без фреймворків і збірки. Іконки - [Lucide](https://lucide.dev) з CDN.

## Структура

```text
frontend/
├── index.html        # Люди (головна) + керування ростером + модалка календаря
├── sklad.html          # Служба "Склад" - тижневий календар, до 3 слот-колонок/день + підсвічування навантаження
├── tec.html              # Служба "ТЕЦ" - тижневий календар, до 2 слот-колонок/день
├── vodii.html               # Водії - тижневий грід навпаки (рядок = людина)
├── masterplan.html            # Загальний майстер-план - календар з динамічними доріжками
├── monitoring.html               # Зведений моніторинг
├── login.html                       # Вхід за PIN
├── admins.html                         # Керування ролями (супер-адмін)
├── css/
│   ├── style.css                          # Базовий дизайн-system (картки, бейджі, сайдбар)
│   └── app.css                               # Стилі нових сторінок, календарів, модалки
└── js/
    ├── api.js                                   # fetch-обгортка, сесія, банер, дата-утиліти (тижні/місяці/години)
    ├── personModal.js                              # модалка календаря людини (2 вкладки)
    ├── weekCalendar.js                                # тижневий календар Склад/ТЕЦ (драг, фіксовані слоти, підсвічування)
    ├── masterPlan.js                                     # тижневий календар майстер-плану (драг, динамічні доріжки)
    └── driverWeek.js                                        # тижневий грід водіїв (людина×день)
```

## Запуск

Разом із бекендом (рекомендовано - фронтенд сервиться на тому самому origin, тож
жодних CORS-налаштувань не треба):

```bash
cd ../backend
npm install && npm run dev
# http://localhost:3000/
```

або через Docker Compose з кореня репозиторію - див. головний `README.md`.
